BDD Cucumber Selenium Java Automation Framework

Overview:

This project is a test automation framework built using Java, Selenium WebDriver, Cucumber and TestNG. The framework follows the Behaviour-Driven Development (BDD) approach using Gherkin feature files and is designed to demonstrate maintainable and reusable UI test automation.

The framework is currently being developed incrementally as a learning project, with features such as the Page Object Model (POM), browser management, reusable utilities, reporting and CI/CD being added over time.


Technologies and Tools:

Java – Programming language

Selenium WebDriver – Browser automation

Cucumber – BDD framework

Gherkin – Writing feature files

TestNG – Test execution and assertions

Maven – Dependency and build management

WebDriverManager – Browser driver management

Git & GitHub – Version control

Eclipse IDE – Development environment



Clone the Repository:


```Bash
git clone https://github.com/babs-sim/bdd-cucumber-selenium-java.git
```

Run the Tests:

The tests can be executed using the Cucumber TestNG runner. Right click TestRunner class and select Run As TestNG Test.
